# Lesson 5: IaC (Terraform)

Цей проєкт демонструє використання інфраструктури як коду (IaC) за допомогою Terraform.  
Мета — створити повністю модульну інфраструктуру, що складається з:

- **S3 bucket та DynamoDB table** для бекенду зберігання стану Terraform
- **VPC** з публічними та приватними підмережами, Internet Gateway, NAT Gateway та маршрутами
- **ECR репозиторію** для зберігання Docker-образів

Проєкт розділено на окремі незалежні модулі для кожного компонента.

## 🧩 Опис модулів

### 1. `s3-backend`
Модуль створює інфраструктуру для зберігання стану Terraform:
- **S3 bucket** з увімкненим версіонуванням
- **DynamoDB table** для забезпечення блокування стейтів (`state locking`)
- Змінні:
  - `bucket_name`: назва S3-бакету
  - `table_name`: назва DynamoDB-таблиці

### 2. `vpc`
Модуль створює базову приватну мережеву інфраструктуру:
- **VPC** з діапазоном `10.0.0.0/16`
- **Публічні підмережі**: `10.0.1.0/24`, `10.0.2.0/24`
- **Приватні підмережі**: `10.0.101.0/24`, `10.0.102.0/24`
- **Internet Gateway** (IGW) для публічних підмереж
- **NAT Gateway** для виходу приватних підмереж в інтернет
- **Маршрутні таблиці** для зв’язку публічних і приватних підмереж з IGW та NAT

### 3. `ecr`
Модуль створює репозиторій в **Amazon Elastic Container Registry (ECR)**:
- Ім’я репозиторію задається змінною `repository_name`
- Увімкнене **сканування образів при завантаженні**
- Повертає **URL репозиторію** для подальшого використання у CI/CD

## 🛠️ Команди для роботи

> Перед використанням переконайтесь, що у вас встановлений `Terraform` та налаштований AWS CLI (`aws configure`).

### Ініціалізація проєкту

```bash
terraform init
```

Ініціалізує бекенд і завантажує модулі та провайдери.

---

### Перевірка змін

```bash
terraform plan
```

Показує, які зміни будуть внесені в інфраструктуру.

---

### Застосування конфігурацій

```bash
terraform apply
```

Застосовує зміни та створює інфраструктуру.  
Підтвердіть `yes`, щоб продовжити.

---

### Знищення інфраструктури

```bash
terraform destroy
```

Видаляє всі ресурси, створені Terraform.
